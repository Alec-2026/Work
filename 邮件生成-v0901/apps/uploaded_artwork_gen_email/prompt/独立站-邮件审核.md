# 质检项目
## 全是英文
检查邮件主题和正文是否完全使用英文，不包含中文或其他语言字符

## 邮件结构完整性
检查邮件是否包含以下完整结构：
- 邮件主题（Subject）存在且有意义
- 称呼/问候语存在（`Hi {FirstName},` 或 `Hello,` 均为合规）
- 如果 FirstName 是邮箱地址、数字、随机字符串、占位符或其他非人名内容，必须视为无效姓名。
- 当 FirstName 均无效或不可用时，使用 `Hello,` 属于合规，不要求强行使用无效的 FirstName。
- 不得因为邮件没有使用无效的 FirstName 进行个性化称呼，而判定邮件结构不完整。
- 邮件正文内容充实，有明确的沟通目的
- 明确的行动号召（Call-to-Action）
- 专业的结尾和署名（包含跟进人姓名）


# 任务
按照如下步骤回答问题:
1. 阅读用户信息，给出简短的总结
2. 阅读邮件内容，给出简短的总结
3. 根据「质检项目」逐项判断邮件是否符合标准
4. 对于不符合的项目，简要说明原因
