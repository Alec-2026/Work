# 质检项目

## 全是英文
主题和正文必须使用英文；允许 URL、百分比和必要的标点，不得出现中文说明文字。

## 邮件结构完整性
必须包含有意义的主题、称呼或问候语、帮助型正文、一个低压力 CTA，以及包含跟进人姓名的完整署名。

## Promotion 行为隐私
不得提及客户浏览、查看、访问、点击、记录或站内行为，不得出现类似“we saw you”或“you viewed”的表达。

## URL 规则
当 Promotion URL 不为空时，正文必须包含且只能包含一个 HTML `<a>` 链接；该 URL 只能出现在 `<a>` 标签的 `href` 属性中，且 `href` 必须等于提供的基础 URL：{{promotion_url}}。
当 Promotion URL 为空时，正文不得包含任何 `<a>` 链接，也不得编造或显示 URL。链接文字不能是原始 URL；客户可见文字中不得直接出现 URL。
`<a>` 只能包裹需要点击的 Promotion 文字，不得包裹 `You can explore`、`You can review`、`here` 或其他 CTA 文案；整个链接句应位于回复型 CTA 之前。
不得出现 URL 查询参数、UTM 参数、Markdown 链接语法或未替换的链接标记。
不得仅因为基础 URL 出现在合法 `<a href="...">` 属性中而判定 URL 规则不通过；URL 规则只检查 HTML 结构、href 匹配和客户可见文字。

## Loyalty Tier 规则
只有输入中的 Loyalty Tier 有效时，才允许使用对应会员折扣：Partner 5%、Pro 8%、Elite 10%。
上述会员折扣只适用于 Member Promotion；其他 Promotion 类型不得在正文中提及会员等级、会员折扣或会员权益。
Starter 和 Builder 不得承诺折扣；空值或未知值不得推断会员等级或折扣。
不得自行增加优惠叠加、最低消费、截止日期或其他会员权益。

## 内容边界
Promotion 主题只能用于个性化沟通方向，不得推断客户已经准备某个项目、产品、数量、预算或采购计划。
不得承诺未经输入确认的具体优惠机制、库存、交期或价格。
